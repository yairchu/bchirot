# תכלס, בחירות

אבטיפוס בעברית לשאלון בחירות עם הומור עדין. HTML, CSS ו־JavaScript, ללא תהליך בנייה וללא שרת ששומר תשובות.

## הרצה מקומית

```sh
npm run dev
```

פותחים http://127.0.0.1:5173. נדרשים Node.js לבדיקות ו־Python 3 לשרת המקומי. אפשר גם להגיש את `dist/` בכל שרת קבצים סטטיים.

```sh
npm run check
npm test
```

## מה עובד

- בחירת כמה נושאים, או מסלול בלעדי של הסתמכות על אדם אחר. ביטול המסלול מחזיר את הבחירות הקודמות.
- בחירה וחיפוש בין 38 פתקים, שאלת רובוט, ושאלת המשך למשתמשי עכבר בלבד.
- הכפתור מתחלף פעם אחת במעבר עכבר, ועדיין מאפשר להמשיך. מקלדת ומגע אינם דורשים את הבדיחה.
- חישוב קצר, תוצאה המשקפת במפורש את הפתק שהמשתמש הזין, והתחלה מחדש לפי עמדות.
- במסלול הנושאים מוצג סיכום ומוסבר שהמשך השאלון בפיתוח. אין חישוב התאמה מומצא.
- ממשק מותאם לנייד, תמיכה בהפחתת תנועה, וכיווניות מימין לשמאל.

## תוכן ונתונים

הנושאים הראשוניים הם הצעה לעריכה. רשימת הפתקים נמצאת ב־`dist/parties.js`, ולוגיקת המסלול ב־`dist/flow.js`. נתוני הפתקים נלקחו ב־21.10.2026 מ־[bechirot.fyi](https://bechirot.fyi/lists/26), מקור משני המפנה לפרסומי ועדת הבחירות. האתר הרשמי חסם את בקשת האימות בזמן הפיתוח; לפני השקה יש לאמת את כל הרשימות והאותיות מול [ועדת הבחירות](https://www.gov.il/he/pages/candidates-lists-26). השמות קוצרו לתצוגה והפתקים מסודרים לפי אותיות, ללא דירוג.

התשובות חיות בזיכרון הדפדפן בלבד ומתאפסות ברענון. אין אנליטיקה, cookies או אחסון תשובות. הפונט נטען מ־Google Fonts, עם Arial כחלופה. פריסת Sites פרטית עשויה לדרוש הזדהות לצפייה, בנפרד מהשאלון עצמו.
