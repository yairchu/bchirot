# תכלס, בחירות

אבטיפוס בעברית לשאלון בחירות. מסך פתיחה ושאלה אחת בכל מסך, עם טקסט גדול. HTML, CSS ו־JavaScript ללא תהליך בנייה.

## הרצה מקומית

```sh
npm run dev
```

פותחים http://127.0.0.1:5173. נדרש Python 3 לשרת המקומי. אפשר גם להגיש את `dist/` בכל שרת קבצים סטטיים.

לבדיקות נדרשים Node.js ותלויות הפיתוח:

```sh
npm ci
npm run check
npm test
```

## מה עובד

- מסך פתיחה עם כפתור התחלה.
- שתי אפשרויות TODO ניתנות לבחירה במקביל. בחירת מסלול הסתמכות על אדם אחר מאפירה ומשביתה אותן; ביטולו מחזיר את הבחירות הקודמות.
- אפשרות ההסתמכות על אדם אחר מופיעה ראשונה, עם הדגשת קיצור הדרך.
- בחירה וחיפוש בין 38 פתקים ושאלת רובוט.
- במחשב עם עכבר, תשובת ״לא״ מובילה ל״האם אתה בטוח?״ עם אפשרות אחת. במעבר עכבר, ״אני בטוח״ מתחלף בקטע מונפש של ״עזוב, לא משנה״ למשך שנייה, ואז ממשיך אוטומטית לחישוב התוצאות. אין צורך ללחוץ.
- מיקוד מקלדת מפעיל את אותו קטע. במכשיר ללא עכבר השלב כולו מדולג.
- תשובת ״כן״ לשאלת הרובוט מפעילה קטע קצר של ״מעריך את המודעות העצמית״, ואז ממשיכה אוטומטית לחישוב, במחשב ובנייד.
- תוצאה המשקפת את הפתק שהמשתמש הזין, והתחלה מחדש. מסלול העמדות מסתיים ב־TODO מפורש.
- שני הכפתורים בתוצאה חוזרים ישירות לשאלה הראשונה עם בחירות מאופסות. בחירה באפשרויות TODO מובילה למסלול שעדיין בפיתוח.
- כפתורי אחורה וקדימה בדפדפן משחזרים בחירות ומעברים בין שאלות. שלבי האנימציה האוטומטיים חולקים רשומת היסטוריה אחת, והאנימציות נעצרות כשחוזרים אחורה.
- תמיכה בנייד, בכיווניות מימין לשמאל ובהעדפה להפחתת תנועה.

## תוכן ונתונים

רשימת הפתקים נמצאת ב־`dist/parties.js`, ולוגיקת המעבר ב־`dist/flow.js`. נתוני הפתקים נלקחו ב־21.10.2026 מ־[bechirot.fyi](https://bechirot.fyi/lists/26), מקור משני המפנה לפרסומי ועדת הבחירות. לפני השקה יש לאמת אותם מול [ועדת הבחירות](https://www.gov.il/he/pages/candidates-lists-26). השמות קוצרו לתצוגה והפתקים מסודרים לפי אותיות.

התשובות נשארות בדפדפן ונשמרות גם במצב ההיסטוריה של הלשונית כדי לאפשר אחורה וקדימה. רענון פותח את מסך הפתיחה. התשובות אינן נשלחות לשרת ואינן מופיעות בכתובת העמוד; אין אנליטיקה או cookies. הפונט נטען מ־Google Fonts, עם Arial כחלופה.
