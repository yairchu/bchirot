# תכלס, בחירות

אבטיפוס בעברית לשאלון בחירות. מסך פתיחה ושאלה אחת בכל מסך, עם טקסט גדול. HTML, CSS ו־JavaScript ללא תהליך בנייה.

## הרצה מקומית

```sh
npm run dev
```

פותחים http://127.0.0.1:5173. נדרש Python 3 לשרת המקומי. אפשר גם להגיש את `dist/` בכל שרת קבצים סטטיים.

שרת הפיתוח מבטל שמירת קבצים במטמון כדי למנוע ערבוב גרסאות אחרי שינויים. לאחר עדכון קוד השרת צריך לעצור ולהפעיל מחדש את `npm run dev`. אם נשמרו קבצים ישנים בספארי, מבצעים פעם אחת Reload Page From Origin ‏(⌥⌘R). כשל בטעינת השאלון מציג הודעה עם ״פרטי התקלה״ במקום להשאיר עמוד ריק.

בנוסף, שרת הפיתוח מוסיף לכתובות ה־JavaScript, לייבואי המודולים ול־CSS מזהה גרסה לפי תוכן הקבצים. כל שינוי מקבל כתובות חדשות ברענון הבא, גם בדפדפן ששמר מודולים ישנים. הקבצים ב־`dist/` אינם משתנים; ההתאמה נעשית רק בתשובות שרת הפיתוח.

לבדיקות נדרשים Node.js ותלויות הפיתוח:

```sh
npm ci
npm run check
npm test
```

## מה עובד

- מסך פתיחה עם כפתור התחלה.
- הנושאים ״דת ותחבורה״ ו״מלחמה וחלום״ ואפשרות TODO ניתנים לבחירה במקביל. בחירת מסלול הסתמכות על אדם אחר מאפירה ומשביתה אותם; ביטולו מחזיר את הבחירות הקודמות.
- ליד כל קטגוריה מוצגת תוספת השאלות לפי מה שכבר נבחר, ובתחתית מוצג הסך הכולל. שאלות הנטל ו־7 באוקטובר משותפות לשתי הקטגוריות ומופיעות פעם אחת. במסלול עם משרתים, דת ותחבורה כוללת 5 שאלות עם בחירת הנושאים, מלחמה וחלום 6, ושתיהן יחד 8. ההסתעפות ללא צבא מעדכנת את המסלול ואת הספירה. [כללי המסלול והספירה](docs/question-flow.md).
- שאלת החלום ב״מלחמה וחלום״ מציגה שתי אפשרויות: ארץ ישראל השלמה או שלום בר־קיימא, עם דילוג. הבחירה מוסיפה נקודת זיקה אחת לרשימות שעבורן נמצא חזון תואם, עם פירוט המקורות והמגבלות. [מיפוי החזון](docs/visions.md).
- מסלול ״דת ותחבורה״ מתחיל בגשר יהודית, נעים בסופ״ש וההגעה להצלת חיים בשבת, ורק אז עובר לשירות בצבא. שאלות הנטל פוצלו לשני עמודים: מי צריך לשרת, ואילו משימות הצבא צריך לשאת. כאשר נבחרת ״מלחמה וחלום״, שאלת החלום פותחת את המסלול. אחריה מגיעות בחירת המשרתים ושאלת המשימות, בסדר הזה; קבוצות השירות מסודרות גברים לא חרדים, נשים, חרדים. בלי משרתים מופיעה אזהרה במקום המד. הסימון הראשון מציג את המד, ביטול כל הסימונים מחזיר את האזהרה, והמד ממשיך עם אותם ערכים בשאלת המשימות שאחריה. המשך ללא משרתים מוביל ל״איך נישאר מוגנים?״ עם ״אלוהים ישמור״, ״לא יודע, לא נראה לי קריטי״ וחזרה לבחירה. המסלול הזה אינו מנוקד ומדלג על עמוד המשימות. במסלול עם משרתים, מלחמה וחלום מציגה עמוד משימות נפרד עם חוות מבודדות ושותפים לביטחון, עם כפתור המשך יחיד שמציג ״דלג״ כשהוא ריק. גם בשאר הדילמות אין כפתור דילוג נפרד; ביטול תשובה מחזיר את הכיתוב ל״דלג״. המד בו מצטבר מהשירות ומהמשימות, וכיסוי הניקוד נפרד לכל עמוד. [המקורות וכללי הניקוד](docs/burden-and-threat.md).
- אפשרות ההסתמכות על אדם אחר מופיעה ראשונה, עם הדגשת קיצור הדרך.
- ב״דת ותחבורה״ מופיעה שאלת קבוצות השירות, לצד שלוש דילמות: בניית גשר יהודית, עיצוב השירות של ״נעים בסופ״ש״ וההיערכות להסעת לוחמים וכוחות הצלה בבוקר 7 באוקטובר. בשנייה אפשר לבחור הרחבת שירות מוסדר, איסור או מצב קיים. בשלושתן יש ״לפרטים נוספים״ עם מקורות ואפשרות לדלג.
- אפשר להמשיך משאלת הנושאים בלי לסמן דבר: מופיע קטע קצר של ״גם לבחור מה חשוב זו החלטה״, ואז מתחילים את הדילמות בלי לסמן נושאים בשם המשתמש.
- בחירה ישירה בין 38 פתקים ואפשרות נוספת של פתק לבן, ולאחריה שאלת רובוט. פתק לבן ריק מסומן כקול פסול לפי הסבר ועדת הבחירות.
- ליד ״קה״ מופיע פתק מומצא ״קקה״ עם הכיתוב ״לשחרר את הצב״. בחירה בו והמשך חושפים את בדיחת ״בקיא בחומר״ ומחזירים אוטומטית לבחירת פתק אחרי שבע שניות לקריאה; הוא אינו מוביל לתוצאה ואינו חלק מנתוני המפלגות.
- במחשב עם עכבר, תשובת ״לא״ מובילה ל״האם אתה בטוח?״ עם אפשרות אחת. במעבר עכבר, ״אני בטוח״ מתחלף בקטע מונפש של ״עזוב, לא משנה״ למשך שנייה, ואז ממשיך אוטומטית לחישוב התוצאות. אין צורך ללחוץ.
- מיקוד מקלדת מפעיל את אותו קטע. במכשיר ללא עכבר מופיע אותו שלב, ואחרי השהיה של 700 אלפיות שנייה מתחילה ההחלפה אוטומטית. לחיצה אינה נדרשת, והמסלול כולל ארבע שאלות גם בנייד.
- תשובת ״כן״ לשאלת הרובוט מפעילה קטע קצר של ״מעריך את המודעות העצמית״, ואז ממשיכה אוטומטית לחישוב, במחשב ובנייד.
- במסלול הסמכות, התוצאה משקפת את הפתק שהמשתמש הזין. במסלול העמדות, השאלות שנבחרו מובילות לניקוד מצטבר, עם פירוט לפי שאלה וכיסוי המקורות לכל מפלגה. דילוג אינו עמדה ואינו מוסיף ניקוד. העדפת יוזמה מיידית בשאלת 7 באוקטובר מורידה נקודה אחת לליכוד כהערכת אחריות להיערכות משרד התחבורה בראשות מירי רגב. לחלופה השנייה אין ניקוד. תשובה שאינה מנוקדת מקבלת הסבר ללא טבלת מפלגות כשהיא היחידה. אם אין תשובות, לא מוצגת טבלת מפלגות. [מודל הניקוד](docs/bridge-scoring.md) מתעד את המשקלים ואת מגבלות המקורות.
- התוצאות מפרידות בין התאמות חיוביות, ציוני אפס ומחלוקות. כשיש רק ניקוד שלילי או אפס, הכותרת מציינת שלא נמצאה התאמה חיובית, כך שרשימה יחידה עם מינוס אינה מוצגת כהמלצה.
- אם הרשימה שנבחרה הודיעה על פרישה, התוצאה מוחלפת בעדכון עם מקור והצעה לקבל המלצה חדשה או לחזור לבחירה לפי עמדות. כחול לבן מוגדרת כך לפי הודעת הפרישה מ־19.10.2026. [תיעוד העדכונים והמקורות](docs/party-notices.md).
- שני הכפתורים בתוצאה חוזרים ישירות לשאלה הראשונה עם בחירות מאופסות. בחירה באפשרויות TODO מובילה למסלול שעדיין בפיתוח.
- כפתורי אחורה וקדימה בדפדפן משחזרים בחירות ומעברים בין שאלות. שלבי האנימציה האוטומטיים חולקים רשומת היסטוריה אחת, והאנימציות נעצרות כשחוזרים אחורה.
- תמיכה בנייד, בכיווניות מימין לשמאל ובהעדפה להפחתת תנועה.

## תוכן ונתונים

רשימת הפתקים נמצאת ב־`dist/parties.js`, ולוגיקת המעבר ב־`dist/flow.js`. נתוני הפתקים נלקחו ב־21.10.2026 מ־[bechirot.fyi](https://bechirot.fyi/lists/26), מקור משני המפנה לפרסומי ועדת הבחירות. לפני השקה יש לאמת אותם מול [ועדת הבחירות](https://www.gov.il/he/pages/candidates-lists-26). השמות קוצרו לתצוגה והפתקים מסודרים לפי אותיות. שמות ואותיות נבדקו מחדש ב־22.10.2026 מול אותו מקור; פרסום ועדת הבחירות החזיר 403 בגישה האוטומטית.

התשובות נשארות בדפדפן ונשמרות גם במצב ההיסטוריה של הלשונית כדי לאפשר אחורה וקדימה. רענון פותח את מסך הפתיחה. התשובות אינן נשלחות לשרת ואינן מופיעות בכתובת העמוד; אין אנליטיקה או cookies. הפונט נטען מ־Google Fonts, עם Arial כחלופה.
