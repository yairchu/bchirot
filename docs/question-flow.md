# קטגוריות, שאלות משותפות וספירה

`dist/flow.js` מכיל קטלוג שאלות אחד: סדר, קטגוריות, מפתח תשובה, שם השדה והאם השאלה משמשת לניקוד. בחירת קטגוריות יוצרת איחוד של השאלות שלהן, בסדר קבוע; שאלה משותפת מופיעה פעם אחת.

״מלחמה וחלום״ מתחילה בחלום, בלי לבחון היתכנות או מחיר: ארץ ישראל השלמה או שלום בר־קיימא. בחירה מוסיפה נקודת זיקה לחזון מתועד לפי [כללי החזון](visions.md), ומצטרפת למכנה כיסוי המקורות. אפשר לדלג עליה. פרטי המסלול וספירת השאלות אינם משתנים לפי התשובה לשאלת החלום.

## תוספת השאלות

- לפני בחירה: תחבורה מוסיפה 3 שאלות, מלחמה וחלום מוסיפה 2.
- אחרי בחירת תחבורה: מלחמה וחלום מוסיפה רק את שאלת החלום — שאלה אחת.
- אחרי בחירת מלחמה וחלום: תחבורה מוסיפה רק את הגשר ונעים בסופ״ש — שתי שאלות.
- שתי הקטגוריות יחד כוללות 4 שאלות תוכן. עם שאלת בחירת הנושאים יש בסך הכול 5.

המספר ליד קטגוריה שכבר נבחרה מציין את התרומה שלה לפי סדר הבחירה. לכן סכום התרומות של הקטגוריות המסומנות שווה למספר השאלות שנוספו. ביטול קטגוריה מעביר את השאלות המשותפות לקטגוריה שנותרה, ומעדכן את המספרים. קטגוריה שעדיין לא נבחרה מציגה כמה שאלות היא תוסיף כעת.

סדר השאלות עצמו אינו תלוי בסדר בחירת הקטגוריות: החלום ראשון אם נבחר, אחריו הגשר, נעים בסופ״ש והשאלה המשותפת. ההתקדמות מחושבת מאותה רשימה כמו הספירה במסך הנושאים.

## ניווט ותוצאות

בחירה ודילוג משתמשים באותו מסלול. אחורה וקדימה משחזרים את בחירות הנושאים, סדר בחירתם, המספרים, התשובות והמסלול. התחלה מחדש מאפסת גם את החלום. שאלות שאינן במסלול אינן נכללות בתוצאות גם אם קיים להן ערך במצב הדפדפן.

מסלול הסמכות נשאר בן ארבע שאלות, ומשבית את כל בחירות הקטגוריות תוך שמירתן. בחירה ב־TODO בלבד מובילה למסך הפיתוח הקיים ואינה מפרסמת שאלות שטרם נכתבו. המשך ללא נושאים משמר את הקטע הקצר ואת ברירת המחדל של שלוש שאלות התחבורה, בלי לסמן קטגוריה בשם המשתמש.
